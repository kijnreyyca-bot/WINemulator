About Virtual PC

Both desktops include a Virtual PC powered by v86. It runs real x86 code in your browser and can boot a Windows 98, FreeDOS or Linux disk image that you supply. No operating-system images are bundled.

x86 only v86 does not support 64-bit x86. Windows XP images may boot slowly and are not guaranteed.
